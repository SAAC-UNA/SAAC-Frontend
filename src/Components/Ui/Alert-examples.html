Documentación de uso

Cómo usar el componente Alert

Uso básico:

<Alert variant="error" message="Error al cargar datos" />

Con acción y título personalizado:

<Alert
  variant="error"
  title="Error del servidor"
  message="HTTP error! status: 500"
  action={{
    label: "Reintentar",
    onClick: handleRetry
  }}
  onDismiss={handleClose}
/>

Usando variantes pre-definidas:

{AlertVariants.backendError("HTTP error! status: 500", handleRetry)}

Variantes disponibles:

  • error - Errores del sistema, backend, validación
  • success - Operaciones exitosas, confirmaciones
  • info - Información general, notificaciones
  • warning - Advertencias, estados de atención
