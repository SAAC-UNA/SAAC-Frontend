# Ampliacion

El modulo Ampliacion agrupa las solicitudes de extension de tiempo asociadas a entregables.

## Submodulos

| Submodulo | Ruta | Condicion de acceso en frontend |
| --- | --- | --- |
| Mis Solicitudes | `/solicitudes-ampliacion/mias` | `cap.extension.view` o `solicitudes_ampliacion.view` |
| Gestionar Solicitudes | `/solicitudes-ampliacion/gestionar` | Contexto con ciclo y proceso, mas `cap.extension.manage` o permisos de aprobar/rechazar |
