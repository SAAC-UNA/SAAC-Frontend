# Informes

El modulo Informes agrupa la gestion de enlaces y las pantallas de informes de acreditacion.

## Submodulos

| Submodulo | Ruta | Condicion de acceso en frontend |
| --- | --- | --- |
| Gestion de Enlaces | `/gestion-enlaces` | Contexto con ciclo y proceso, mas `cap.reports.access` o permisos de reportes |
| Informes de Acreditacion | `/informes-acreditacion` | Contexto con ciclo y proceso, mas `cap.reports.access` o permisos de reportes |
